# Kapeniross Coffee

A React-based web application for an artisan coffee shop featuring an interactive menu, live search, cart drawer, and product previews.

## Features

- **Interactive Cart Drawer**: Add items, update quantities, remove items, and run mock checkout.
- **Global Search**: Instant menu filtering by item name or description.
- **Quick View Modal**: Inspect coffee details, ingredients, and pricing.
- **Toast Notifications**: Interactive feedback alerts for user actions.
- **Responsive Dark UI**: Glassmorphism aesthetic built with custom CSS.

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Variables, Flexbox/Grid)
- **Linter**: Oxlint

## Project Structure

```text
src/
├── assets/        # Menu data and image assets
├── components/    # Reusable UI sections (Hero, Menu, Cart, Contact, etc.)
├── pages/         # Page layouts
├── App.jsx        # Main application component & global state
└── main.jsx       # Entry point
```
